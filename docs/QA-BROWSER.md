# 브라우저 확인 기록 (L2·L3)

- 확인 일시: 2026-11-12, `npm run dev`(개발 서버) + 앱 내장 브라우저, 실제 외부 서비스 사용
- 보안 헤더(CSP, X-Frame-Options, nosniff)를 켠 상태에서 확인했고 화면 오류는 없었다. 콘솔 오류 1건은 일부러 빈 칸으로 계산을 눌러 받은 검증 오류(400)다.

| 시나리오 | 결과 |
|---|---|
| L2 필수 칸을 비우고 계산 | 칸별 오류 문구("교통비 실비를 입력해 주세요") 표시, 계산 안 함 ✅ |
| L3 과정 A + 대전 동구→서울 강남, 기차 실비 30,000원(왕복) | 열차요금 상한 21,600원 적용, 교통비 21,600원×2, 초과 8,400원과 이유, 식비 108,000원, 합계 151,200원, 항목마다 근거 조항 ✅ |
| L3 "쉬운 말로 설명 보기" | 서명 검증 통과 후 항목별 설명 5개 표시(숫자는 결과 값 그대로) ✅ |
| L3 `/operator` 명단 4줄(정상 2 + 시내 1 + 형식 오류 1) | 3명 인식·잘못된 줄 안내, 진행 1/1, 합계 399,200원(시내 이순신 0원), CSV 내려받기 버튼 표시 ✅ |
| 화면 구성 | 증빙 사진 미리보기, FAQ 7개, 규정 질문 상자 표시 ✅ |

확인하지 못한 것: 과정 선택부터 결과까지 1분(SC-2)을 사람이 재는 일, 모바일 폭 화면, 실제 CSV 파일 내려받기 동작.
