## 점검에서 드러난 문제 (통과했지만 사용 중 부딪힐 수 있는 것)

- **열차요금 조회 실패가 20건 중 7건**(case-04, case-09, case-12, case-15, case-16, case-18, case-20)에서 있었다. 이 중 제주 항공(case-04·15·16)·시내(case-18)·울릉군(case-20)은 의도된 경우다.
- **직통 열차가 없는 구간은 요금이 조회되지 않는다** (case-12 광주송정↔대전: TAGO 결과 0건). 이 경우 교통비 인정을 보류하고 운영자 문의를 안내한다.
- **같은 도시 안 이동(case-09 부산 해운대구→남구)은 대표 철도역이 같아 요금이 없다.** 시내 판정은 시·군 단위(구가 달라도 같은 시)로 바꿔서, 같은 시 안 이동은 시내로 처리돼 여비가 지급되지 않는다.


## 알려진 한계

- 오피넷 오픈 API는 날짜별 가격이 없어 '출장 당일'이 아니라 조회한 날의 전국 평균가를 쓴다.
- TAGO `adultcharge`는 API 값 그대로이며 실제 승차권 요금과 다를 수 있다.
- 시·군·구 좌표와 대표 철도역은 실습용으로 정한 근사값이다.
- SC-2의 '과정 선택부터 결과 표시까지 1분'은 사람이 입력하는 시간이 포함되어 있어 자동으로 재지 못했다(서버 응답 시간만 측정).
